# Монополии

Данный проект анализирует, на какие клетки игровой доски «Монополия» игроки попадают чаще всего. Результат помогает выстроить оптимальную стратегию покупки улиц.

## Цель

Определить распределение посещений 40 клеток поля при случайных бросках двух кубиков. Исследование проводится для 2–6 игроков.

## Реализация

1. Написание модульных тестов (использую методологию TDD).
2. Создание структуры данных с помощью `dataclass`. Перегрузка методов __get__(), __set__() и __getitem__() для удобного заполнения данных.
3. Создание обёртки, ограничивающей работу библиотеки `Matplotlib` для простоты вывода результата.
4. Симуляция броска двух кубиков с учётом нормального распределения суммы граней.

## Гипотеза о распределении

Сумма двух кубиков подчиняется треугольному распределению (дискретный аналог нормального). Это учтено в симуляции.

## Результаты

При большом количестве бросков сильной количесвтенной разницы между полями нету, но при 40 - 100 бросках (начальная стадия игры) наблюдается количесвтенный перевес у следующих полей: Общественная казна 1, Казанская железная дорого, Варшавское шоссе, Электростанция, Арбат, Рублевская, Ростовская, Грузинская, улицы, Щусева и Общественная козна 3. 

Данная статистика наблюдается при эмперических наблюдениях.
